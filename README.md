# Smart Image Toolkit

## Overview

A toolkit that performs real image processing operations and generates new image files.

---

## Features

- Convert image to grayscale
- Resize images
- Generate processed output files
- Dynamic image input

---

## Installation

```bash
pip install pillow
```

---

## Usage

```bash
python toolkit.py
```

---

## Example

```text
=================================
SMART IMAGE TOOLKIT
=================================

Enter Image Path:

photo.jpg

1. Grayscale
2. Resize

Choose Option:
1
```

Output:

```text
Output Generated:

photo_grayscale.jpg
```
